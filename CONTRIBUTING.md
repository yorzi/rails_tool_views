# Contributing to the local draft

Start with AGENTS.md and docs/agent/00_ENTRYPOINT.md. Keep the v0 single-component scope and RubyLLM-free core. Changes need a public-API reproduction, focused positive/negative tests, relevant acceptance rows and one Progress Ledger section plus Work-ID trailer per authored commit. Run the offline core and optional adapter suites and package smoke; do not label local results as remote CI or live-provider proof.

Use main unless the owner asks for a branch. Do not push, merge, publish, contact maintainers or change license/name without authorization. This unpublished draft has no approved OSS license; external contribution and distribution terms must be settled before public release.

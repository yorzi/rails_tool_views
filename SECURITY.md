# Security

This local v1 is unpublished and has not received independent security review. Do not post secrets, customer data, raw payloads or exploit instructions in a public issue. A verified private maintainer disclosure channel must be configured before public release; none is claimed to exist yet.

The host must resolve actor and tenant from authenticated server state, provide deny-by-default component/action policies, authorize domain records independently of props, keep CSRF enabled and project data before persistence. ToolViews rejects unregistered renderers/actions, extra parameters, client policy text, forged sources/targets, stale revisions and mismatched replays. The only extra parameters tolerated are `commit` and `button`, which Rails' submit helpers post; their values are never read. The non-Turbo redirect after a committed action follows `Referer` only to the same host. Native escaping depends on trusted host templates. Registration rejects any nested schema that is untyped, empty, open or an array without `items`, so a closed props or arguments object cannot be reopened from the inside. Engine-scoped request and SQL bind redaction and metadata-only notifications reduce logging exposure without altering host logs; host SQL/SDK logging and retention still need review.

The gem stores approved display props/state and structured interaction values. It does not store transcripts, API credentials or raw business-record dumps by itself. Hosts control export/deletion and must not place sensitive data into these fields. Database handlers share Surface's transaction; external calls require host idempotency/outbox. Agent deliveries use a lease and stable delivery key, with explicit retry; a host must deduplicate across uncertain remote outcomes.

Supported transports are JSON and Turbo. ActionCable is absent. No executable model-generated HTML, JS, Ruby, arbitrary remote schema resolution or URL fetch is supported. Security coverage maps SEC-01..18 in the acceptance matrix; channel-specific checks remain N/A while broadcasting is disabled.

Mounted controllers inherit the host's ApplicationController; review inherited authentication filters and helpers. ValidationError returns bounded approved field feedback, so handlers must avoid returning private values. Engine request logs mask every field except routing metadata, and Engine models redact their JSON columns in SQL binds and `#inspect`; custom host attributes/SDK logs require separate review. Renderer and adapter exceptions are host exceptions: they are passed to `Rails.error` and logged with class and message, so host code must not put secrets in exception messages. V1 query/resolver/dispatcher independently authorize current role, tenant and associations, and compare host versions across Surfaces. The synthetic identity selector and local reply outbox are reference fixtures, not production authentication or external delivery.

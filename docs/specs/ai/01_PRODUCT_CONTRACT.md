# Product contract
Source: [PRD](../02_PRODUCT_VISION_PRD.md), [FR/AC](../04_FEATURE_MVP_SPECS.md).
- User: Rails developer reusing an existing Partial or ViewComponent as a safely callable presentation tool.
- Promise: same trusted component renders from ordinary Rails or optional AI tools; actions can execute Rails service or hand structured response to agent.
- Must: Registry, schema validation, deterministic presentation, optional RubyLLM present_ui, Surface/restore, secure Action, agent return, Hotwire UI, runnable OSS sample.
- Won't: mandated AI provider, arbitrary code generation, new cross-platform protocol, SaaS or rich composed UI V0.
- Evidence required before independent release: real technical spike, security negative tests, external developer trials, measurable glue-code value.
Use-case catalogue: [UC-01..10](../supporting/06_USE_CASES_AND_REFERENCE_DEMOS.md), with P0 ChoiceCard/AI-free Rails (UC-01/10), P1 admin/support/result review (V1), remaining P2 exploratory. Distinguish candidate adopters from validated demand.

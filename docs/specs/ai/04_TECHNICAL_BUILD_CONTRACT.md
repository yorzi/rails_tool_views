# Technical build contract
Source: [05 architecture](../05_TECHNICAL_ARCHITECTURE.md), [09 safety](../09_DEPLOYMENT_SECURITY_OPERATIONS.md), [supporting threat model](../supporting/04_SECURITY_VERIFICATION.md).
Rails-native engine, Registry/Presentation Core, ActiveRecord Surface, authorized server Actions, Turbo/Stimulus; adapters outside core. Explicit JSON Schema, no reflection from arbitrary initializer or untrusted constantization. RubyLLM optional and not eagerly required. Test without provider gems installed. Use transactions, revision/lock_version, action/call correlation idempotency; render only trusted Partial/ViewComponent. Host business models, authoritative UI Surface state and agent transcript are separate; do not send client policy text to LLM as authorization. One server transition across JSON/Turbo/ActionCable, verified component/action/source, scoped channel/DOM target and no in-process Hash state. Before selecting a dependency, read [pinned upstream source audit](../supporting/05_UPSTREAM_SOURCE_GAP_ANALYSIS.md) and reproduce SP-09..12; favor upstream core reuse without blindly forking or copying tree logic. SQLite test baseline and version-pinned Rails/Ruby CI; verify supported matrix rather than guessing.

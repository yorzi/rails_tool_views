# UX contract
Source: [06 UX](../06_DESIGN_SYSTEM_AND_COPY.md), [06A visuals](../06A_VISUAL_SPEC_AND_PROTOTYPES.md).
Primary UI is a trusted single SelectCard, embedded in ordinary Rails page and optionally chat. Implement ready/loading/empty/invalid/denied/stale/agent-pending/agent-failed states. Keyboard, focus, error associations, responsive 360px minimum. Host controls visual style. Wireframe is reference only; capture state board and browser demo before H1; do not invent canonical branding.
Demo A ChoiceCard (UC-01/10) is the only required V0 UX. Demo B Support Ticket and Demo C Generated Result Review are V1 candidates; see [scenario-specific UX and failure modes](../supporting/06_USE_CASES_AND_REFERENCE_DEMOS.md).

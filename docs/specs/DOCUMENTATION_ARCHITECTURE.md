# Documentation architecture
OddlyNiche owns product intent and frozen approved baseline; independent OSS repo owns code/tests/ADR/current docs after Gate I. Numbered Specs hold canonical intent, supporting/ holds protocol/spike/threat detail, ai/ is agent routing, human/ is concise review. MASTER_SPEC is generated only from manifest.documents. REVIEW is not an implementation authorization. No Q/H2/C/R exists yet.

Reference use-case hypotheses and demo tracks are in `supporting/06_USE_CASES_AND_REFERENCE_DEMOS.md`; they do not supersede canonical FR/AC or scope gates.
